# 编译与运行指南

## 1.下载

安装好git，使用下面命令：

```
git clone git@github.com:Light-City/CPlusPlusThings.git
```

## 2.编译环境

- IDE推荐

  [CLION](https://www.jetbrains.com/clion/)

- 编译器

  [GCC/G++](https://ftp.gnu.org/gnu/gcc/)


## 3.编译本项目

方式一: vscode + bazel
